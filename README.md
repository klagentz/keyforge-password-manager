# Password Manager in C

A command-line password manager written in C for securely storing, managing, and generating passwords. The project focuses on practicing C programming, file handling, data structures, command-line interfaces, and cybersecurity concepts.

Planned Features
- Add, edit, search, and delete password entries
- Store credentials persistently using files
- Master password authentication
- Password generation
- Password encryption
- Hidden password input
- Automatic session locking
- CLI-based interface
- Secure handling of sensitive data

This project is primarily an educational exercise focused on developing practical C programming and cybersecurity skills. Security-sensitive functionality will rely on established cryptographic libraries and best practices rather than custom cryptographic algorithms.
